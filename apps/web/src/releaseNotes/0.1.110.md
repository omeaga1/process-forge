# A unit panel you can read at a glance

- **The unit panel is laid out in zones.** A status bar stays pinned at the top with whether the unit runs, its first figures and Undo. Below it come cards for Inputs, Results, Checks and Reference (Streams, Equations and Physics as tabs).
- **Inputs come first and stay quiet.** An input row only speaks up when it matters: it is out of range, near an edge, moves a check that fails, or has a one-click fix. Each input is judged only by the checks it can actually move, so one failing check no longer turns every row red.
- **Checks show their gauges, and failing ones open with their levers**, so you see what to change without hunting through the panel.
