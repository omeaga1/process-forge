# Drop a unit onto a pipe

- **Splice a unit into a pipe.** Drag a unit that isn't piped yet onto a pipe. The pipe lights up, and when you let go it's re-piped through the unit: tank → pump → filler. A unit that can't take what the pipe carries stays put, and the status bar says why. Undo takes it back out.
- **Old run figures stay with their run.** After you edit the line, the "where the time went" breakdown still describes the flowsheet the run was made on.
