# A short spec sheet for every unit

- **Open a unit's Design tab** and it starts on the few specifications that define it (a pump: flow, pressure rise, efficiency, motor). Everything else is under **More settings**, still there.
- **Each result once.** The same quantity in other units (a flow in m³/s beside gal/min, a shaft power beside the duty) is no longer listed twice.
- **The feed folds away** once a pipe brings it in: the line supplies it.
- **One units switch**, As written · US · SI, instead of a dropdown on every row. Click a unit to change just that one.
- **Folded until you want them**: Solve for a result, Sensitivity study, Streams, Equations, Physics.
- **Drawing tab**: agitator and jacket only on vessels they are drawn on; baffles and demister, which never drew anything, are gone.
- New units Claude designs mark their key specs, so they start short too.
