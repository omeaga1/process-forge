# Less reading, more engineering

- **Long descriptions fold away.** Library listings, the unit's header and every setting now show one short line. Click **More** to see the rest as a few bullet points.
- **The Publish dialog shows your card as you type,** with a length meter, so listings stay short enough to scan.
- **Settings rows are one line each.** Help under a parameter or calculated value is trimmed to a single line; hover it for the full text.
- **Tighter wording across the app and website:** the AI model dialog, the unit's Ask tab, the MCP guide and the website's pages say the same in far fewer words.
- **Claude now writes short.** When it designs a unit, the brief tells it how long descriptions and labels may be, and the engine flags anything that would show as a wall of text. The built-in units were rewritten to the same rules.
