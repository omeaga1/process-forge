# Batch reactors can take turns

- **Batch reactors have a Start delay.** Set it in minutes on the reactor's settings, and the reactor waits that long before its first batch. Use it to stagger two reactors that feed one surge tank, so one discharges while the other brews.
- **The beverage bottling example runs at its stated speeds.** Its filler, accumulation table and labeler had their settings saved under old names, so the simulation used defaults (a 40/min labeler instead of 280/min). Lines built from it now read the speeds they show.
