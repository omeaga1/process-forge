# A calmer unit studio

- **The page you get when you double-click a unit has been redesigned.** The Overview and Design tabs lose the nested boxes, the capital-letter labels and the tinted pills. Sections now sit on thin lines, titles are plain sentences, and the key figures (rate, duty, what each stream carries) are large and easy to read.
- **The unit header is simpler.** The unit's name is bigger, its kind sits above it as plain text, and its description reads as a paragraph rather than being clipped in a card.
- **The Design tab's navigation is a row of text tabs** (Settings, Streams, Equations, Checks, Physics) with an underline, instead of icon pills.
- **"Design a unit op" is rewritten.** It asks "What does the unit do?", offers four examples to start from (wax belt, brine crystalliser, plate heat exchanger, rotary dryer), has a single "Design it" button, and tucks the paste-a-contract box away until you want it.
