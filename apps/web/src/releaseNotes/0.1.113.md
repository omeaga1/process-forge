# Pin a run, change the line, see what moved

- **Compare runs.** Pin a run in the copilot, change the line, and run again. The copilot shows what you changed and what it did: rate, the last unit's OEE, how long the line waited, and on which unit. On the paint example, a 30-min reaction instead of 45 takes the line from 11.1 to 13.8 cans/min.
