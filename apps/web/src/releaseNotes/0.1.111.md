# A receipt for every plan, and nothing overwritten

- **Every plan Claude applies leaves a receipt.** It lists what changed (units, streams, settings from and to), a run of the line before and after on the same seed, and whether the flowsheet read back shows every change. You see it in the assistant panel here, and Claude Desktop draws the same receipt in the chat for plan_changes and apply_changes.
- **History: go back to any earlier version.** Before a plan lands, before a file is opened over a project, before going back, on every save and every ten minutes of editing, ProcessForge keeps the flowsheet as it was. Open History (the clock button beside Save) to go back. Going back keeps the flowsheet as it is now too, so it can be undone the same way.
- **Go back to before a plan in one click**, from the plan's receipt.
