# Where the line's time went, and runs too short to trust

- **See where the time went.** After a run, the copilot shows how long the end of the line waited, and on which unit and phase. On the bottling example: 42% waiting while the carbonator reacts, 21% while it fills.
- **Too-short runs say so.** If a batch unit finished fewer than two batches, the status bar flags the run as mostly start-up and names a run length to use instead.
- **No more "limits the line at about 0".** A unit that hasn't delivered yet is named without a made-up rate.
