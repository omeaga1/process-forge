# Where the line's time went, and alcohol mixtures that boil right

- **See where the time went.** After a run, the copilot shows how long the end of the line waited, and on which unit and phase. On the paint example over 8 h: 54% while the reactor reacts, 12% while it fills.
- **Too-short runs say so.** If a batch unit finished fewer than two batches, the status bar flags the run as mostly start-up and names a run length to use instead.
- **Ethanol, methanol, IPA and acetone in water boil where they should.** Bubble points now use NRTL activity coefficients: 40 % ethanol boils at 82.7 °C, not 93.6. Designed units can call gamma(), bubble_point() and bubble_vapour().
- **No more "limits the line at about 0".** A unit that hasn't delivered yet is named without a made-up rate.
