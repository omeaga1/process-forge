# What's new, every time

- **This window.** After each update the app shows what changed, once. Open it again any time: Ctrl+K, "What's new".
- **Claude's tools, checked.** Below shows the ProcessForge version Claude is running and the one it has ready. If Claude is behind, restart Claude.
- The update banner now says what is in an update before you restart.
- Claude's tools keep a log of their own updates (`~/.process-forge/mcp/updater.log`) and update under Claude's built-in runtime, where they could stall before.
