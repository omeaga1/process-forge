# No more sliders, a calmer unit page

- **Sliders are gone.** Every setting on a unit is now a value you type (in any unit of its kind), with the spec sheet showing the range over which the design passes. The red-and-yellow slider view and its switch are removed, and so are the sliders on built-in units.
- **At a glance is quieter.** The check gauges are thinner and neutral, with a small status dot instead of loud colour bars. Only a check that is close to its limit, warns or fails stands out.
- The Units switch (As written, US, SI) now sits on its own, in the same style as the rest of the page.
