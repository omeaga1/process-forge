Code signing policy

Free code signing provided by SignPath.io, certificate by SignPath Foundation.

What is signed

The Windows installers (.exe and .msi) published on the GitHub releases page. They are built by GitHub Actions from the public source in github.com/omeaga1/process-forge, from a version tag, and nothing else is signed with this certificate.

Separately, every release is signed with the project's update key, which the desktop app checks before installing an update.

Team roles

  • Committers and reviewers: omeaga1. Changes from anyone else are reviewed before they are merged.
  • Approvers (who approve each signing request): omeaga1.

All team members use multi-factor authentication for GitHub and SignPath.

Privacy

This program will not transfer any information to other networked systems unless specifically requested by the user or the person installing or operating it. What it connects to, and when, is listed in the privacy statement.
